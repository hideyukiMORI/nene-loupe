## MSIXの実測をやり直す手順

管理者権限（UAC）が2回要る。証明書と鍵はファイルにしない。作業木の中で行う。

```powershell
# 1. Release の exe を正規の経路で作る（out/release/stage/NeNeLoupe.exe ができる）
pwsh -NoProfile -File ./eng/package-release.ps1

# 2. 検証用の証明書を、持ち出し不可の鍵で証明書ストアに作る（Subject はスクリプトの -Publisher と同じにする）
$cert = New-SelfSignedCertificate -Type Custom -Subject 'CN=NeNe Loupe MSIX Local Test' `
    -KeyUsage DigitalSignature -CertStoreLocation Cert:\CurrentUser\My -KeyExportPolicy NonExportable `
    -NotAfter (Get-Date).AddDays(14) `
    -TextExtension @('2.5.29.37={text}1.3.6.1.5.5.7.3.3', '2.5.29.19={text}')

# 3. 包んで署名する（out/msix/ に .msix ができる）
pwsh -NoProfile -File ./eng/package-msix.ps1 -CertificateThumbprint $cert.Thumbprint

# 4. 公開側の証明書だけを書き出し、管理者として「ローカル コンピューター → 信頼されたユーザー」に入れる
Export-Certificate -Cert $cert -FilePath out/msix/local-test.cer
#    （管理者の PowerShell で）Import-Certificate -FilePath <上の .cer> -CertStoreLocation Cert:\LocalMachine\TrustedPeople

# 5. 入れる・消す
Add-AppxPackage -Path out/msix/NeNeLoupe-v0.2.0-windows-x64.msix
Get-AppxPackage NeNeLoupe.LocalTest | Remove-AppxPackage
```

終わったら必ず片付ける: `Cert:\LocalMachine\TrustedPeople`（管理者）と`Cert:\CurrentUser\My`から証明書を消す。
後者は`Remove-Item -Path Cert:\CurrentUser\My\<拇印> -DeleteKey`で鍵ごと消える。

注意:

- **実測の前に`%LOCALAPPDATA%\NeNeLoupe\settings.v1.txt`の控えを取ること。** 包んだアプリは、このファイルがあるとそれを
  その場で書き換える。今回はhideの設定が書き換わり、控えから戻した。
- 包んだアプリの起動は`explorer.exe shell:AppsFolder\<PackageFamilyName>!NeNeLoupe`。
- 窓を探すときは、hideが使っている別のルーペ（同じ窓クラス`NeNeLoupe.Window`）と取り違えないよう、起動前からある窓を除く。
- 窓の題名に出る値は保存された形式に従う（HEXとは限らない）。`verify-window.py`の色の検査はHEXを前提にしているので、
  先に形式をHEXまで切り替える。
- 実測はロックされていない対話デスクトップが必要。
