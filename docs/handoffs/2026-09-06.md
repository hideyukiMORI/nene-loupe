## 実装の要点

- 色変換の唯一の実装は `core/ColorText`、状態所有者は `application/LoupeController`。
- Clipboard/SettingsStore/SystemAppearance portをappでWin32 adapterに結線する。
- ルーペ240×64 DIP、レンズ7×7画素を8倍。中心は(32,32) DIP。
- チップ(86,3)-(150,27)、ギア(211,3)-(238,27)、値(86,29)-(238,61)が操作領域。
  採取失敗中はチップ・値がドラッグ領域に戻り、ギアは有効。
- 形式はHEX → CMYK → HSL → HSV → RGB → HEX。保存の初期値はsystem/hex/topmost。
- 設定モーダルは失敗文言の行を加えて高さ392 DIP。図形アイコンはGDIで描く。
- コピーは所有HWNDを関連付け、メモリ確保後にクリップボードを空にする。失敗を成功表示しない。
- スキーマ1は `%LOCALAPPDATA%\NeNeLoupe\settings.v1.txt` の4行。
  `schema=1`、`theme=dark|light|system`、`format=rgb|hex|cmyk|hsl|hsv`、`layer=topmost|normal`。
  保存は同じディレクトリの一時ファイルから置換。旧版移行は未定義。
