NeNe Loupe
===========

必要な環境
----------

- Windows 10 version 2004 以降（x64）
- DWM（Desktop Window Manager）が有効な環境

起動方法
--------

1. ZIPを任意のフォルダーへ展開します。
2. NeNeLoupe.exeを起動します。インストールは不要です。

Windowsが発行元を確認できない旨を表示する場合があります。この配布物はコード署名されていません。

使い方
------

- 左側のルーペは、ルーペ中心の背面を8倍で表示します。
- 色の値をクリックすると、表示中の文字列をコピーします。
- 形式名をクリックすると形式を巡回し、右クリックすると形式を直接選べます。
- 歯車からテーマと「常に最前面」を変更できます。
- ルーペまたは背景をドラッグすると移動し、EscまたはAlt+F4で終了します。

設定は %LOCALAPPDATA%\NeNeLoupe\settings.v1.txt に保存されます。
本体は画面キャプチャから除外されるため、通常のスクリーンショットや画面共有には映りません。
HDR・広色域・ICCプロファイルを使った色管理は対象外です。
