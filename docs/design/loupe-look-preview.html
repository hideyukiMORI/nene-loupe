CurrentZoom.dc.html

現状 — 4 倍拡大
地 RGB(24,26,30)／レンズ (4,4) 56×56（7×7 画素 × 8 倍）／中心印は 10×10 の黒枠と内側 1 DIP の白枠／「HEX」(68,9)-(156,26) RGB(150,156,169)／値 (68,28)-(158,55) RGB(245,246,250)／どちらも Segoe UI semibold 13 DIP。
HEX
#FF8000
気づいた点は 3 つ。(1) 窓に外周の枠が無いので、暗い机上では端が消える。(2) 値が proportional の Segoe UI なので、30 ms ごとの再採取で桁幅が揺れる。(3) 値欄が 90 DIP しかない。仕様例の区切りで書いた 100, 100, 100, 100 は 98.8 DIP、360, 100%, 100% は 96.3 DIP で、どちらも入らない（実測・Segoe UI semibold 13 DIP）。詰めれば 88.1 DIP で入るが余りは 1.9 DIP。そもそも FR-006 のコピー、FR-007 の切替、FR-009 のギアを置く場所が無い。ここが幅を広げる本当の理由で、桁数はその次。
