## MSIXの実測をやり直す手順

管理者権限（UAC）が要る（証明書の導入と削除。WACKを回すならその分も）。証明書と鍵はファイルにしない（`.pfx`などはCNF-009が拒否する）。作業木の中で行う。

```powershell
# 0. hide の設定ファイルの控えを取る
Copy-Item "$env:LOCALAPPDATA\NeNeLoupe\settings.v1.txt" D:\NeNeLoupe\probe\settings-backup-<日付>\

# 1. Release の exe と ZIP を正規の経路で作る（package-msix.ps1 は ZIP の中の exe との一致も検査する）
pwsh -NoProfile -File ./eng/package-release.ps1

# 2. 検証用の証明書を、持ち出し不可の鍵で証明書ストアに作る（Subject はスクリプトの -Publisher の既定値と同じにする）
$cert = New-SelfSignedCertificate -Type Custom -Subject 'CN=NeNe Loupe MSIX Local Test' `
    -KeyUsage DigitalSignature -CertStoreLocation Cert:\CurrentUser\My -KeyExportPolicy NonExportable `
    -NotAfter (Get-Date).AddDays(14) `
    -TextExtension @('2.5.29.37={text}1.3.6.1.5.5.7.3.3', '2.5.29.19={text}')

# 3. 検証用の身元で包んで署名する（out/msix/NeNeLoupe-v<版>-windows-x64.msix。-Submission は付けない）
pwsh -NoProfile -File ./eng/package-msix.ps1 -CertificateThumbprint $cert.Thumbprint

# 4. 公開側の証明書だけを out/（Git の除外済み）へ書き出し、管理者として「ローカル コンピューター → 信頼されたユーザー」に入れる
Export-Certificate -Cert $cert -FilePath out/msix/local-test.cer
#    （管理者の PowerShell で）Import-Certificate -FilePath <上の .cer> -CertStoreLocation Cert:\LocalMachine\TrustedPeople

# 5. 入れる。包んだアプリの起動は explorer.exe shell:AppsFolder\<PackageFamilyName>!NeNeLoupe
Add-AppxPackage -Path out/msix/NeNeLoupe-v<版>-windows-x64.msix

# 6. 片付ける。終わったら 3 か所とも 0 件であることを確かめる
Get-AppxPackage NeNeLoupe.LocalTest | Remove-AppxPackage
Remove-Item -Path "Cert:\CurrentUser\My\$($cert.Thumbprint)" -DeleteKey
#    （管理者の PowerShell で）Remove-Item Cert:\LocalMachine\TrustedPeople\<拇印>
```

WACKの手順と結果は`docs/quality/gate-proofs.md`第16節、シェルが返すアイコンの確かめ方は第15節にある。
窓の題名に出る値は保存された形式に従う（HEXとは限らない）。実測はロックされていない対話デスクトップが必要。
